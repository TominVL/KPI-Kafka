**Мета роботи**

 Побудувати базову систему моніторингу для енергетичних баз даних з використанням Prometheus та Grafana, налаштувати збір метрик від Apache Kafka та Cassandra, створити dashboard для візуалізації даних та налаштувати алерти для критичних ситуацій.

**Хід роботи**

 	Було розгорнуто середовище для виконання лабораторної роботи у WSL.
Встановлено та налаштовано систему моніторингу Prometheus і середовище для збору метрик. <br>
 	Створено програму-генератор метрик, яка імітує роботу теплових електростанцій.
Програма формує дані про викиди CO₂, SO₂ та NOₓ, тип палива, ефективність систем очищення, рівень відповідності екологічним нормам і можливі екологічні штрафи. <br>
 	Реалізовано експорт згенерованих метрик у форматі, сумісному з Prometheus.
Prometheus було налаштовано на регулярне зчитування метрик з локального HTTP-endpoint. <br>
 	Запуск системи моніторингу пройшов успішно, усі метрики коректно збираються та відображаються в інтерфейсі Prometheus. На графіку показано зміну потужності теплових електростанцій у часі, що дозволяє спостерігати динаміку навантаження енергоблоків під час їх роботи. Видно, що потужність змінюється в певних межах, що є нормальним для режимів регулювання генерації електроенергії та підтверджує коректну роботу моделі й системи збору даних.

  	У конфігурації Prometheus підключено файл правил алертів.
Алерти реагують на перевищення допустимих норм викидів, зниження ефективності систем очищення, підвищені викиди SO₂ та ризик екологічних штрафів.

 У Grafana створено дашборд для візуалізації екологічних показників. На дашборді відображено: <br>
1)	середні викиди CO₂, SO₂ та NOₓ у часовому розрізі; <br>
2)	рівень використання допустимого ліміту викидів (compliance); <br>
3)	середню ефективність систем очищення; <br>
4)	поточні екологічні штрафи.<br>

**Висновок**

У ході лабораторної роботи було реалізовано систему моніторингу екологічних показників теплових електростанцій з використанням Prometheus та Grafana. Було змодельовано збір даних про викиди CO₂, SO₂ та NOₓ, ефективність систем очищення, рівень відповідності екологічним нормам і можливі екологічні штрафи.
Створений дашборд у Grafana дозволяє наочно відстежувати динаміку викидів у часовому розрізі, оцінювати поточний стан compliance та ефективність систем очищення. Застосування агрегування метрик зробило візуалізацію зрозумілою та зручною для аналізу.
Також було налаштовано алерти в Prometheus, які забезпечують автоматичне виявлення потенційних екологічних порушень. Отримані результати підтверджують коректну роботу системи моніторингу та можливість її використання для контролю екологічних показників у реальному часі.
